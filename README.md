## ✦ Le Manifeste / The Manifesto

**Atelier Minuit** is an independent studio dedicated to the craft of high-precision software, native Apple Silicon architectures, and transparent hardware interoperability.

We reject bloated commercial software, forced cloud dependencies, and fake telemetry. Our work is guided by three non-negotiable principles:

* **Local Sovereignty:** Software must run 100% on device. No tracking, no phone-home analytics, and no remote kill switches.
* **Hardware Truth:** Direct, transparent communication with physical sensors and hardware registers. No synthetic illusions.
* **Artisan Precision:** Lightweight, clean-room C99 engines and pure SwiftUI interfaces built strictly to Apple's Human Interface Guidelines (HIG).

## ✦ L'Œuvre Principale / Featured Work

###  [TankControl — Native macOS Utility & Driver Suite](https://github.com/giorgiogpt/TankControl)

A complete, clean-room driver, RIP engine, and modern management utility for **HP Smart Tank 500 Series** continuous ink (CISS) multifunction hardware on Apple Silicon (M1/M2/M3/M4).

* **Native RIP Engine (`rastertopcl3gui`):** Pure C99 PCL3GUI Mode 10 raster encoder with run-length compression and ColorSync ICC calibration.
* **Continuous InkSaver Technology:** Seamless ink reduction from 0% to 75% featuring **EdgePreserve™** typographic contour retention and dot gain micro-perforation.
* **Fast Draft Mode (300 DPI):** Single-click high-speed draft output for rapid document throughput.
* **Integrated Optical Scanning:** Dedicated USB vendor-class driver and local eSCL bridge for Apple *Image Capture*.
* **Multilingual from Core:** Full in-app, PPD, installer, and documentation localization across 5 languages (Español, English, Português, Français, Deutsch).
* **Autonomous Bundle:** Zero external dependencies on Homebrew; packaged with `@rpath` internal dynamic linkage.
